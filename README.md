# Module 05 Assignment — Problem Solving with AI (Claude Code + JavaScript)

This repository contains JavaScript coding practice programs completed 
as part of Module 05 assignment.

## Programs Included

| File | Description |
|------|-------------|
| `celsius-fahrenheit.js` | Converts Celsius temperature to Fahrenheit |
| `factorial.js` | Calculates the factorial of a given number |
| `palindrome.js` | Checks whether a word is a palindrome |
| `sum-array.js` | Calculates the sum of all elements in an array |
| `fizzbuzz.js` | Prints Fizz, Buzz, or FizzBuzz from 1 to 15 |

## How to Run

Make sure [Node.js](https://nodejs.org) is installed, then run any file:

\`\`\`bash
node celsius-fahrenheit.js
node factorial.js
node palindrome.js
node sum-array.js
node fizzbuzz.js
\`\`\`
